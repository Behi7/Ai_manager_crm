# Ai_manager_crm

Интеллектуальный ИИ-ассистент и менеджер квалификации для amoCRM на базе FastAPI, Redis, PostgreSQL и Google Gemini.

Сервис автоматически обрабатывает входящие сообщения от клиентов, ведет естественный диалог, защищен от prompt-инъекций, производит поэтапную квалификацию лидов и обновляет данные в amoCRM (сделки, кастомные поля, примечания).

---

## 🚀 Основные возможности

1. **Интеграция с amoCRM**:
   - Автоматическая регистрация и обработка вебхуков.
   - Поддержка нескольких аккаунтов (мульти-аккаунт).
   - Безопасное хранение токенов amoCRM в зашифрованном виде (Fernet AES-128).
   - Отправка ответов через системные примечания amoCRM или запуск Salesbot.

2. **Debounce-очередь сообщений (Redis)**:
   - Объединяет серии коротких сообщений от клиента за настраиваемый интервал (таймаут) в единый контекст перед отправкой в нейросеть.
   - Исключает дублирование ответов и спам при быстрой печати клиента.

3. **Коммуникатор на базе Google Gemini**:
   - Естественное общение в роли менеджера компании.
   - Гибко настраиваемый системный промпт для каждого пайплайна/аккаунта.
   - «Правило одного вопроса»: ИИ не перегружает клиента и задает не более одного ненавязчивого вопроса за раз.
   - Защита от prompt-инъекций и системных манипуляций.

4. **Квалификация и автозаполнение полей**:
   - Автоматическое извлечение ключевых данных (бюджет, город, потребность, сроки и т.д.) из хода диалога.
   - Запись выявленных параметров в кастомные поля сделки amoCRM.

5. **Мультимодальность**:
   - Поддержка обработки голосовых сообщений и изображений, прикрепленных клиентом в чате amoCRM.

6. **Административная панель (Admin UI)**:
   - Доступна по адресу `/admin`.
   - Управление подключенными аккаунтами amoCRM, выбор воронок, настройка маппинга полей, редактирование промптов и тестирование генерации ответов.

## 🛠 Технологический стек

- **Backend**: Python 3.11+, FastAPI, Uvicorn, Pydantic v2
- **База данных**: PostgreSQL 16 (asyncpg, SQLAlchemy 2.0 Async, Alembic)
- **Кэш и очереди**: Redis 7
- **Нейросеть / LLM**: Google Gemini 2.5 Flash API (multimodal)
- **Безопасность**: Cryptography (Fernet symmetric encryption)
- **Контейнеризация**: Docker, Docker Compose

## 📦 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/Behi7/Ai_manager_crm.git
cd Ai_manager_crm
```

### 2. Создание и активация виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте шаблон `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните переменные в файле `.env`:
- `DATABASE_URL` — строка подключения к PostgreSQL.
- `REDIS_URL` — адрес Redis.
- `SECRET_KEY` — 32-байтный Fernet ключ (можно сгенерировать командой `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`).
- `GEMINI_API_KEY` — API-ключ Google Gemini.
- `BASE_URL` — публичный URL сервиса для приема вебхуков (например, через ngrok: `ngrok http 8080`).

### 5. Запуск инфраструктуры (PostgreSQL + Redis)

Запустите контейнеры через Docker Compose:

```bash
docker compose up -d
```

### 6. Применение миграций базы данных

```bash
alembic upgrade head
```

### 7. Запуск приложения

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8080 --reload
```

Приложение будет доступно по адресу:
- **Админ-панель**: [http://localhost:8080/admin](http://localhost:8080/admin)
- **Swagger документация**: [http://localhost:8080/docs](http://localhost:8080/docs)
- **Health check**: [http://localhost:8080/health](http://localhost:8080/health)
